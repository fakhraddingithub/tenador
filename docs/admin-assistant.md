# دستیار ادمین (JEV)

دکمهٔ دایره‌ای دستیار در پایینِ سمت چپ تمام صفحات پنل نمایش داده می‌شود و چت در همان گوشه باز می‌شود. چت پس از اولین باز کردن بارگذاری می‌شود و با بستن پنجره یا جابه‌جایی بین صفحات پنل حفظ می‌شود؛ با بارگذاری مجدد صفحه پاک می‌شود. مسیر قدیمی `/p-admin/assistant` به داشبورد هدایت می‌شود. اتصال مستقیم به Gemini API؛ مدل روی سرور ارائه‌دهنده اجرا می‌شود.

## تنظیمات

کلید موجود در محیط سرور خوانده می‌شود؛ هیچ کلیدی در کد یا مرورگر قرار نمی‌گیرد:

```dotenv
GEMINI_API_KEY=...
# اختیاری؛ پیش‌فرض زیر در تست واقعی تأیید شد
GEMINI_MODEL=gemini-flash-lite-latest
# خاموش کردن مستقل قابلیت
ADMIN_ASSISTANT_ENABLED=false
# اختیاری، فقط وقتی شبکهٔ سرور به پراکسی نیاز دارد
GEMINI_PROXY_URL=http://127.0.0.1:PORT
```

برای فعال بودن، `ADMIN_ASSISTANT_ENABLED` را حذف کنید یا `true` قرار دهید. پس از تغییر محیط، سرور را دوباره اجرا کنید. روی هاست، پراکسی localhost کامپیوتر توسعه قابل استفاده نیست. پراکسی فقط برای درخواست‌های این سرویس اعمال می‌شود؛ dispatcher بقیهٔ برنامه تغییر نمی‌کند.

مجوز جدید `assistant.use` دسترسی به چت را می‌دهد. نقش دسترسی کامل آن را خودکار دارد؛ برای نقش‌های محدود از پنل نقش‌ها اعطا کنید. این مجوز به‌تنهایی اجازهٔ خواندن داده نمی‌دهد: هر ابزار مجوز بخش خودش را بررسی می‌کند. شمارش فعالیت ادمین‌ها به `admins.viewActivity` و گزارش مالی به `analytics.view` نیاز دارد. لینک صفحه‌ها نیز از رجیستری دسترسی عبور می‌کنند.

## رفتار و هزینه

- معمولاً دو درخواست: مسیریابی JSON، سپس نوشتن جواب بر پایهٔ نتیجهٔ واقعی. حداکثر سه درخواست برای جست‌وجوهای وابسته.
- حداکثر ۳ ابزار در هر مرحله، ۸ ردیف برای فهرست، ۶ پیام قبلی و ۴۵۰۰ نویسه تاریخچه. جمع و شمارش روی تمام نتایج منطبق در MongoDB محاسبه می‌شوند، نه روی نمونهٔ فهرست.
- حداکثر ۵ ثانیه برای هر پرس‌وجوی DB، ۲۵ ثانیه برای هر درخواست Gemini، سقف کلی ۱۰۵ ثانیه. تکرار خودکار درخواست پولی وجود ندارد.
- سقف هر ادمین ۱۰ سؤال در دقیقه و ۱۰۰ سؤال در روز؛ شمارندهٔ اتمیک در کالکشن مستقل `assistantquotas`. ایندکس `_id` برای صحت محدودیت کافی است. برای پاک‌سازی خودکار، ایندکس TTL `expiresAt` را با اسکریپت اختصاصی زیر بسازید.
- گفتگو در حافظهٔ صفحه است و روی سرور یا localStorage ذخیره نمی‌شود. لاگ فقط تعداد فراخوانی و توکن مصرفی را ثبت می‌کند. تاریخچهٔ گفتگو و نتایج قبلی منبع معتبر آمار نیستند؛ داده دوباره خوانده می‌شود.
- فیلدها صریحاً مجاز شده‌اند؛ رمزها، OTP، توکن‌ها، آدرس‌ها و اسناد پرداخت ارسال نمی‌شوند. سؤال و دادهٔ مجاز لازم برای پاسخ به Gemini می‌روند. شرایط نگهداری/استفاده از داده در حساب ارائه‌دهنده باید با کاربرد واقعی سازگار باشد.
- ابزارها فقط خواندنی‌اند. تنها نوشتن‌های داخلی: سهمیهٔ خود دستیار و ثبت مشاهدهٔ دفتر فعالیت با سازوکار فعلی ممیزی.

## دامنه و دقت

محصولات، سفارش‌ها، کاربران، پرداخت‌ها، اقساط، تیکت‌ها، مقاله‌ها، محصولات دست‌دوم، برندها، ورزش‌ها و دسته‌ها: فهرست، شمارش، گروه‌بندی و جمع فیلدهای عددی مجاز. گزارش مالی از همان محاسبات داشبورد استفاده می‌کند و یورو و تومان را جدا نگه می‌دارد. موجودی انبار جداگانه، قیمت نهایی زنده، متن پیام تیکت و جست‌وجوی آزاد روی همهٔ فیلدها فعلاً ابزار ندارند؛ مدل باید محدودیت را بگوید.

فعالیت ادمین‌ها از `AdminActivity` خوانده می‌شود. ایجادهای موفق اصلی و `related` با شناسهٔ یکتای محصول/ادمین شمارش می‌شوند؛ رویداد مجوز یا تلاش ناموفق ایجاد محصول نیست. نام مبهم باعث سؤال تکمیلی می‌شود. پاسخ باید «طبق فعالیت‌های ثبت‌شده» بگوید؛ لاگ‌های قبل از فعال شدن ممیزی یا ثبت‌های ازدست‌رفته قابل بازسازی نیستند. حذف/ویرایش شمارش موجودیت‌های یکتا است؛ اکشن‌های تخصصی مثل تغییر قیمت در ویرایش عمومی نیستند. اگر لاگ حذف‌شدن رویدادهای اضافه را اعلام کند، عدد حداقلِ ثبت‌شده است.

«امروز» و «دیروز» بر اساس تهران و «این ماه» بر اساس ماه شمسی محاسبه می‌شوند. لینک‌ها را سرور می‌سازد؛ متن مدل به HTML یا لینک دلخواه تبدیل نمی‌شود. محصول صفحهٔ جزئیات خواندنی مستقل ندارد؛ برای ادمین بدون مجوز ویرایش، لینک فهرست محصولات نمایش داده می‌شود.

## بررسی

```sh
npm run test:assistant
node scripts/rbacCoverage.mjs
npm run build
node scripts/ensureAssistantIndexes.mjs
```

تست‌های دستیار از MongoDB موقت و دادهٔ ساختگی استفاده می‌کنند و هیچ درخواستی به مدل نمی‌فرستند. ایجاد ایندکس را در محیط مقصد اجرا کنید؛ فقط کالکشن سهمیهٔ دستیار را تغییر می‌دهد.
